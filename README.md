# Chem Bench

Study hub for Chemistry Unit 1: Nomenclature and the Mole.

Six topics, each with a Learn tab (rules and worked examples) and a Practice tab (unlimited, randomized, self-checking questions with step-by-step explanations). Includes a full periodic table with search. Progress is saved in the browser.

Everything is in a single file, `index.html`, with no build step and no dependencies beyond Google Fonts.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
