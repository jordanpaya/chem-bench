# Chem Bench

Study hub for Honors Chemistry. Opens on Unit 2; switch units at the top of the dashboard.

- **Unit 1 · Nomenclature & the Mole:** elements and symbols, atomic structure and isotopes, average atomic mass, ions to memorize, naming compounds, the mole.
- **Unit 2 · Atomic Theory & Periodic Trends:** Bohr model and light, orbitals and electron configurations, periodic properties, families of the periodic table, nomenclature and formulas.

Each topic has a Learn tab (rules, worked examples, interactive tools) and a Practice tab (unlimited randomized questions that check themselves and explain the answer, including the reasoning for trend questions). Includes a searchable periodic table and a light/dark toggle. Progress is saved in the browser.

Everything is in a single file, `index.html`, with no build step and no dependencies beyond Google Fonts.
